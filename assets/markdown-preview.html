GW-1731 Manual Red/Green Test Plan

Overview

Goal: reproduce the current CSV-import misassignment (red) and then confirm the fix (green) for textbook Roofing 101 (how to read blueprints) (textbookId 5, classId 2) using the sample CSV located at Roofing 101 (how to read blueprints) - 20250919035444.csv.

Pre-Checks

  • Ensure you have trainer credentials with access to import textbooks for class “How to Read Roof Blueprints” in the dev/staging environment.

  • Copy the CSV to your local machine; do not modify the contents between runs.

  • Record the current timestamp for later cleanup: SELECT NOW();.

  • Baseline the period ordering so you know which periods are currently “oldest”:

    SELECT id, title, "startDate", "order"
FROM dlsu."EvaluationTemplates"
WHERE "classId" = 2 AND "type" = 'SCHOOL'
ORDER BY "order";

Red Run (Before Fix)

  1. In the UI, open Textbooks → Create/Import Textbook.

  2. Select class “How to Read Roof Blueprints” and upload the sample CSV.

  3. Complete the import and note the start timestamp (import_start_time).

  4. Verify the mis-assignment via SQL:

    SELECT et.title,
       et."order",
       COUNT(t.id) AS topics_added
FROM dlsu."Topics" t
JOIN dlsu."EvaluationTemplates" et
  ON et.id = t."evaluationTemplateId"
WHERE t."textbookId" = 5
  AND t."createdAt" >= TIMESTAMP '<<import_start_time>>'
GROUP BY et.title, et."order"
ORDER BY et."order";

    Expected red result: counts skewed to the lowest order periods (oldest school years).

  5. Capture the query output (screenshot or export) as evidence of the bug.

Cleanup Between Runs

  • Remove the imported topics so the green run starts clean:

    DELETE FROM dlsu."Topics"
WHERE "textbookId" = 5
  AND "createdAt" >= TIMESTAMP '<<import_start_time>>';

  • Confirm cleanup succeeded (SELECT COUNT(*) on the same filter returns 0).

Green Run (After Fix)

  1. Deploy/apply the code changes introducing the school-year filtering/sorting.

  2. Repeat the import using the same UI steps and CSV.

  3. Record the new import_start_time.

  4. Re-run the verification query:

    SELECT et.title,
       et."order",
       COUNT(t.id) AS topics_added
FROM dlsu."Topics" t
JOIN dlsu."EvaluationTemplates" et
  ON et.id = t."evaluationTemplateId"
WHERE t."textbookId" = 5
  AND t."createdAt" >= TIMESTAMP '<<import_start_time>>'
GROUP BY et.title, et."order"
ORDER BY et."order";

    Expected green result: counts appear first on the newest/current-year periods (highest startDate/order), with older periods untouched.

  5. Optionally confirm via UI by inspecting the textbook’s period view.

  6. Clean up again if needed (same DELETE statement) or retain the data if desired.

Optional Detailed Check

If you need to inspect individual topics:

SELECT t.title,
       et.title AS period_title,
       et."startDate",
       t."createdAt"
FROM dlsu."Topics" t
JOIN dlsu."EvaluationTemplates" et ON et.id = t."evaluationTemplateId"
WHERE t."textbookId" = 5
  AND t."createdAt" >= TIMESTAMP '<<import_start_time>>'
ORDER BY et."order", t."order";

Deliverables

  • Red-run SQL evidence showing incorrect period assignment.
  • Green-run SQL evidence showing correct/current period assignment.
  • Notes on any anomalies or additional cleanup performed.
